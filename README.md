# 📊 Sales Forecasting and Demand Prediction Dashboard

An interactive **Power BI dashboard** built to analyze sales performance, identify trends, and explore future sales patterns using historical transaction data.

## 📌 Project Overview

This project analyzes **12,000 sales transactions** recorded between **2023 and 2025**.

The dashboard provides a clear view of:

- Overall sales performance
- Sales trends over time
- Product-wise performance
- Category-wise sales
- Regional sales performance
- Units sold
- Order volume
- Forecasted sales trends

The goal is to transform raw sales data into meaningful business insights through interactive visualizations.

---

## 📂 Dataset

The dataset contains sales transaction information including:

- 📅 Date
- 🧾 Order ID
- 📦 Product
- 🏷️ Category
- 🌍 Region
- 🔢 Units Sold
- 💰 Unit Price
- 💵 Sales

### Dataset Coverage

- **Records:** 12,000
- **Time Period:** 2023–2025
- **Categories:** Electronics, Furniture, Stationery
- **Regions:** North, South, East, West
- **Products:** Laptop, Phone, Printer, Headphones, Desk, Chair, Pen, Notebook

## 📊 Dashboard Features

### 📅 Sales Trend Analysis
Visualizes sales performance over time to identify changes and patterns across months and years.

### 📦 Product Analysis
Compares sales performance across different products such as laptops, phones, printers, desks, chairs and more.

### 🏷️ Category Analysis
Analyzes sales across:

- Electronics
- Furniture
- Stationery

### 🌍 Regional Analysis
Compares sales performance across:

- North
- South
- East
- West

### 🔮 Sales Forecasting
The dashboard includes a **forecasted sales trend** to provide an indication of future sales patterns based on historical data.
